
# SchedulEasy App

SchedulEasy is a timetable management Android app designed for students and faculty. It allows users to view, create, and manage weekly schedules with ease. Faculty members have special access to edit the timetable, while students can view it in a user-friendly format.



## Features

🧑‍🎓 Student View (read-only access)

👨‍🏫 Faculty/Admin Mode (editable access)

📝 Editable timetable title

⏰ Add custom time slots and subjects

➕ Add/Delete timetable rows

🔍 Scrollable timetable for better visibility

💾 Save timetable using SQLite

📄 Export and share as PDF

⚙️ Settings: Theme, Notifications, Change Password


## Tech Stack

- Language: Java

- UI: XML (Android Studio Layout Editor)

- Database: SQLite

- PDF Export: PdfDocument, FileProvider

- Android SDK: Compatible with Android 5.0 (API 21) and above
